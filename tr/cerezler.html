Çerez Politikası

Web Sitemizde Kullanılan Çerezler Hakkında Bilgilendirme

Son Güncelleme: 17 Kasım 2024

1. Çerez Nedir?

Çerezler, ziyaret ettiğiniz web sitesi tarafından cihazınıza (bilgisayar, tablet veya cep telefonu gibi) depolanan küçük metin dosyalarıdır. Çerezler, web sitesinin düzgün çalışması, daha güvenli hale getirilmesi, daha iyi kullanıcı deneyimi sunması ve web sitesinin performansının analiz edilmesi amacıyla yaygın olarak kullanılmaktadır.

2. Çerez Türleri

Web sitemizde kullanılan çerezler, kullanım amaçlarına göre farklı kategorilere ayrılmaktadır:

2.1. Zorunlu Çerezler

Bu çerezler, web sitesinin düzgün çalışması için mutlaka gereklidir. Bu çerezler olmadan web sitesi düzgün çalışmayacaktır.

  • Oturum Çerezleri: Ziyaretiniz süresince aktif kalır ve tarayıcınızı kapattığınızda silinir
  • Güvenlik Çerezleri: Güvenlik özelliklerini etkinleştirmek için kullanılır
  • Dil Tercihi Çerezleri: Seçtiğiniz dil tercihini hatırlar

2.2. Performans Çerezleri

Bu çerezler, web sitesinin performansını ölçmek ve iyileştirmek için kullanılır.

  • Ziyaretçi sayısını izleme
  • Hangi sayfaların daha popüler olduğunu belirleme
  • Kullanıcıların sitede nasıl gezindiğini anlama
  • Hata tespiti ve düzeltme

2.3. İşlevsellik Çerezleri

Bu çerezler, web sitesinin gelişmiş özellikleri ve kişiselleştirme sunmasını sağlar.

  • Tercihlerinizi hatırlama (dil, bölge)
  • Font boyutu, tema gibi kişisel ayarları saklama
  • Önceki ziyaretlerinizi tanıma

2.4. Analitik Çerezler

Web sitemizin nasıl kullanıldığını anlamamıza yardımcı olan çerezlerdir.

  • Google Analytics çerezleri
  • Ziyaretçi davranış analizi
  • Traﬁk kaynakları takibi
  • Sayfa görüntüleme istatistikleri

3. Web Sitemizde Kullanılan Çerezler

Çerez Adı Türü Süre Açıklama
language_preference Zorunlu 1 yıl Tercih ettiğiniz dili hatırlar
_ga Analitik 2 yıl Google Analytics - Kullanıcıları ayırt eder
_gid Analitik 24 saat Google Analytics - Kullanıcıları ayırt eder
_gat Analitik 1 dakika Google Analytics - İstek oranını sınırlar
cookie_consent Zorunlu 1 yıl Çerez onayınızı saklar

4. Çerezleri Nasıl Kontrol Edebilirsiniz?

Çerezleri kontrol etmek ve yönetmek için tarayıcı ayarlarınızı kullanabilirsiniz. Çoğu tarayıcı, çerezleri otomatik olarak kabul edecek şekilde ayarlanmıştır, ancak bu ayarları değiştirebilirsiniz.

Popüler Tarayıcılarda Çerez Ayarları:

  • Google Chrome: Ayarlar → Gizlilik ve güvenlik → Çerezler ve diğer site verileri
  • Mozilla Firefox: Ayarlar → Gizlilik ve Güvenlik → Çerezler ve Site Verileri
  • Safari: Tercihler → Gizlilik → Çerezler ve web sitesi verileri
  • Microsoft Edge: Ayarlar → Çerezler ve site izinleri → Çerezleri yönet ve sil

Önemli Not: Çerezleri tamamen devre dışı bırakırsanız, web sitemizin bazı özellikleri düzgün çalışmayabilir ve kullanıcı deneyiminiz olumsuz etkilenebilir.

5. Üçüncü Taraf Çerezler

Web sitemizde, hizmet sağlayıcılarımız tarafından yerleştirilen üçüncü taraf çerezler kullanılmaktadır:

Google Analytics

Google Analytics, web sitesi trafiğini analiz etmek için kullanılır. Bu hizmet, ziyaretçilerin web sitemizi nasıl kullandığı hakkında bilgi toplar. Toplanan bilgiler anonim olup, kişisel kimliğinizi belirlemek için kullanılamaz.

Google Analytics gizlilik politikası: https://policies.google.com/privacy

Google Fonts

Web sitemizde Google Fonts kullanılmaktadır. Google Fonts, IP adresiniz gibi bazı bilgileri toplayabilir.

Font Awesome

İkonlar için Font Awesome CDN kullanılmaktadır.

6. Çerez Politikası Güncellemeleri

Bu Çerez Politikası, yasal düzenlemelerdeki değişiklikler veya web sitemizdeki uygulamalarımızdaki güncellemeler doğrultusunda zaman zaman güncellenebilir. Önemli değişiklikler olduğunda, web sitemizde duyuru yapılacaktır.
